This is an unofficial, non-commercial reinforcement-learning research project
for Tiberian Dawn. It contains modified engine and training code and must not be
represented as an official Electronic Arts product.

## Data and assets

This public tree intentionally excludes retail game archives, extracted sprites,
audio, video, commercial game data, and locally supplied `td-data/`. Users must
provide their own legally obtained game data locally.

The showcase GIFs are gameplay documentation, not a distributable game-data
pack. Do not sell them or use them to imply endorsement by Electronic Arts.
