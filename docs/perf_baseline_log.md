# CNC Performance Baseline Log

Use this as the single append-only source for throughput claims.

Every new experiment or optimization should add one row with full command + validity metadata.

## Rules for valid entries

- `start_failures` must be `0.000` to claim throughput.
- Capture command used (exact shell command).
- Include `agents/threads/buffers`.
- Include `train.total-timesteps` and `train.horizon` when using PufferLib.
- Include log path when available.
- If `GameFrameLimit` is set, call out the value.
